# Сайт концертно-экскурсионных программ

Четыре страницы по макету Figma: главная, афиша, карточка концерта и контакты.
Свёрстано на чистом HTML, CSS и JavaScript — без сборщика и внешних библиотек, все шрифты и картинки лежат локально.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | главная: обложка, афиша из двух событий, новости, календарь экскурсий, краткие анонсы |
| `afisha.html` | полный список событий |
| `event.html` | «Антонио Вивальди. Времена года»: программа концерта, состав оркестра, стоимость билетов |
| `contacts.html` | адрес, режим работы кассы, телефоны, карта |

## Запуск

Откройте `index.html` в браузере или поднимите статический сервер:

```bash
python -m http.server 8000
```

Дальше — http://localhost:8000.

## Структура

```
index.html, afisha.html, event.html, contacts.html
styles/style.css      переменные, сетка, компоненты, адаптив
scripts/main.js       календарь на главной: месяцы, свободные даты, выбор дня
assets/fonts/         Fira Sans 400/600/700 + лицензия OFL
assets/images/        фотографии и карта
assets/icons/         пиктограммы для метаданных событий
```

## Как устроено

- Ширина контента — `min(1296px, 100% - 2 * отступ)`, шапка 104 px, фон страницы `#EDEDED`, карточки `#E2E2E2`, акцент `#05B093`.
- Общие блоки (шапка, подвал, карточка события, кнопка) переиспользуются на всех страницах — правится в одном месте.
- Пиктограммы «жанр / время / возраст / календарь» подключены через `::before`, поэтому разметка остаётся текстовой.
- Адаптив: 1180 px — планшет, 900 px — карточки в одну колонку, 620 px — телефон.
- Учтены `:focus-visible`, `prefers-reduced-motion`; у календаря есть `aria-live` и переход по стрелкам клавиатуры.

## Календарь

Свободные даты лежат в объекте `FREE_DAYS` в `scripts/main.js` (ключ — `год-месяц`), для остальных месяцев набор считается по шагу. В макете на месте сетки стоит заглушка из повторяющихся чисел 1–7 — здесь сделаны настоящие даты июля 2026 с теми же подсвеченными днями.
